ENCAIXE NO JOGO

Um armário com quatro espaços

Cabeça → bonéTorso → camisetaPernas → calça ou bermudaPés → par de tênis

Os 16 modelos auditados têm corpo e roupa no mesmo mesh. Bonés usam o osso da cabeça; roupas precisam de uma base preparada, pesos no esqueleto e ocultação das peças antigas. Cada corpo recebe seu ajuste. A API atual guarda uma skin; o armário por partes ainda precisa ser implementado.

Primeiro conjunto de prova: boné SUS + camiseta Nordeste + bermuda de quadra + tênis branco, no Esquerdomacho. Conferir corrida, agachamento, salto e arma na mão antes de ampliar para outros corpos.
